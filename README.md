A make.fun entry for the **Museum of the Year 3000** bounty: write a single line, at most 200 characters, as the museum label a museum in the year 3000 puts beside an ordinary object from today.

## The entry

> Miniature Shampoo, 2026. Guests stole these from hotels and kept them unopened for years, as if they were treasure.

(115 characters. A curator in the year 3000, finding thousands of sealed little hotel shampoo bottles carefully stored in homes, would reasonably conclude they were treasure — the joke is the gap between "treasure" and a 30 ml bottle of free hotel shampoo.)

## Run

```sh
node main.ts
```

This writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with in-code gate checks: single line, non-blank, 1–200 characters.
